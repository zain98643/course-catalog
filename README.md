# Course Catalog Application

A production-ready Course Catalog application built with Next.js 15 (App Router), TypeScript, and Tailwind CSS.

## Features Implemented
- **Dynamic Routing & SSG**: Implemented `/courses/[id]` pages with `generateStaticParams` for pre-rendering static routes.
- **Client Interactivity**: Interactive `LikeButton` client component utilizing React state.
- **Error Handling & Loading**: Custom loading states (`loading.tsx`) and custom 404 pages (`not-found.tsx`).
- **Type Safety**: Strictly typed mock data layer and props using TypeScript.
